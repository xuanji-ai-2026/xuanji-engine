# 玄玑引擎配置端 (Configuration Client)

基于 React 18 + TypeScript + Vite 构建的现代化配置管理系统。

## 技术栈

- **React 18.3.1** - UI 框架
- **TypeScript 5.9.3** - 类型安全
- **Vite 5.3.1** - 构建工具
- **Zustand 4.4.0** - 状态管理
- **Tailwind CSS 3.4.3** - CSS 框架
- **Lucide React** - 图标库
- **React Router DOM** - 路由管理

```bash
npm install
```

### 开发模式

```bash
npm run dev
```

访问 `http://localhost:3000`

### 构建生产版本

```bash
npm run build
```

```bash
npm run preview
```

```bash
npm run type-check
```

## 环境变量

创建 `.env` 文件（参考 `.env.example`）：

```bash
VITE_API_BASE_URL=/api
VITE_APP_TITLE=玄玑引擎配置端
VITE_ENV=development
```

## 开发规范

### 组件开发
- 使用函数式组件 + Hooks
- 使用 TypeScript 严格模式
- 遵循单一职责原则
- 组件使用 PascalCase 命名

### 状态管理
- 使用 Zustand 进行全局状态管理
- 使用 useLocalStorage/useSessionStorage 进行持久化

### 样式
- 使用 Tailwind CSS 实用类
- 使用 cn() 工具函数合并类名
- 避免内联样式

### 类型定义
- 所有数据使用 TypeScript 类型定义
- 使用 interface 定义对象类型
- 使用 type 定义联合类型

## API 集成

API 基础 URL 通过环境变量配置：

```typescript
const API_BASE_URL = import.meta.env.VITE_API_BASE_URL || '/api'
```

所有 API 请求通过 `apiClient` 统一处理：

```typescript
import { apiClient } from '@/api/client'

// GET 请求
const data = await apiClient.get<ResponseType>('/endpoint')

// POST 请求
const result = await apiClient.post<ResponseType>('/endpoint', requestData)
```
