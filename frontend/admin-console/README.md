# 玄玑引擎管理端（Admin Console）

> 基于 React 18 + TypeScript + Vite + Zustand + Tailwind CSS 构建的管理控制台应用

## 技术栈

- **React**: 18.3.1
- **TypeScript**: 5.9.3 (严格模式)
- **Vite**: 5.3.1
- **Zustand**: 4.4.0 (状态管理)
- **Tailwind CSS**: 3.4.3 (样式)
- **React Router**: 6.20.0 (路由)
- **Axios**: 1.6.2 (HTTP 客户端)
- **Recharts**: 2.10.3 (图表)
- **Lucide React**: 0.294.0 (图标)
- **React Hot Toast**: 2.4.1 (通知)
- **Radix UI**: 组件库

## 核心特性

### TypeScript 严格模式
- 启用所有严格类型检查
- 禁用隐式 any
- 禁用不安全的类型操作
- 确保代码类型安全

### 函数式组件 + Hooks
- 所有组件使用函数式写法
- 使用 React Hooks 管理状态和副作用
- 自定义 Hooks 封装可复用逻辑

### Zustand 状态管理
- 轻量级状态管理方案
- 支持 TypeScript 类型推导
- 支持持久化存储
- 简洁的 API 设计

### Tailwind CSS
- 原子化 CSS 框架
- 响应式设计
- 暗黑模式支持
- 自定义主题配置

### 多端适配
- 移动端优先设计
- 响应式布局
- 触摸优化
- 自适应导航

### 隐身激活
- 隐藏系统标识
- 自定义域名
- 隐藏管理入口
- 安全访问控制


## 状态管理

### Stores
- `auth-store`: 认证状态
- `ui-store`: UI 配置
- `theme-store`: 主题设置
- `assistant-store`: 智能助手状态

## 自定义 Hooks

### 可用 Hooks
- `useAuth`: 认证信息
- `usePermission`: 权限检查
- `useLocalStorage`: 本地存储
- `useDebounce`: 防抖
- `useWindowSize`: 窗口尺寸
- `useBreakpoint`: 响应式断点

## 样式系统

### 主题配置
```css
/* 主色调 */
primary: blue-500

/* 强调色 */
accent: purple-500

/* 支持深色模式 */
dark: class based
```

### 动画效果
```css
/* 内置动画 */
animate-fade-in    /* 淡入 */
animate-slide-in   /* 滑入 */
animate-scale-in   /* 缩放 */
```

## 开发规范

### 命名规范
- 组件: PascalCase
- 文件: PascalCase.tsx / PascalCase.ts
- Hooks: camelCase
- 常量: UPPER_SNAKE_CASE
- 工具函数: camelCase

### 目录规范
- 每个功能模块独立目录
- 组件和页面分离
- 公共组件放在 components
- 页面组件放在 pages
