# 小元（Xiaoyuan）- 开发者端智能助手适配层

> 为开发者提供智能助手服务，包含 API 管理、插件开发、SDK 管理和代码审查等核心能力。

---

## 概述

小元是玄玑引擎的智能助手适配层，专为开发者端设计，提供以下核心功能：

- **API 管理协助**: 接口查询、文档生成、API 测试
- **插件开发协助**: 插件模板、API 对接指导、测试建议
- **SDK 管理协助**: 版本管理、集成指导、更新提醒
- **代码审查协助**: 质量检查、安全漏洞提示、性能优化建议

## 快速开始

### 安装

```bash
# 通过 npm 安装
npm install @xuanji-ai/xiaoyuan-adapter

# 或通过 yarn
yarn add @xuanji-ai/xiaoyuan-adapter

# 或通过 pnpm
pnpm add @xuanji-ai/xiaoyuan-adapter
```

### 基本使用

```typescript
import { XiaoyuanAdapter } from '@xuanji-ai/xiaoyuan-adapter';

// 创建适配器实例
const adapter = new XiaoyuanAdapter({
  apiKey: 'your-api-key',
  coreApiUrl: 'http://localhost:5000/api',
  wsEndpoint: 'ws://localhost:5000/ws',
});

// 连接到核心服务
await adapter.connect();

// 创建会话
const session = await adapter.createSession('developer-123');

// 发送消息
const response = await adapter.handleMessage(session.id, {
  type: 'text',
  role: 'user',
  content: '帮我生成一个 API 文档',
  serviceType: 'api_management',
  timestamp: Date.now(),
});

console.log(response.content);
```

### 核心组件

#### 1. XiaoyuanAdapter（主适配器）
- 管理连接生命周期
- 处理消息路由
- 管理会话状态
- 提供统一的事件接口

#### 2. 服务层
- **ApiManagementService**: API 端点管理、文档生成、测试
- **PluginDevelopmentService**: 插件模板、开发指导
- **SdkManagementService**: SDK 版本管理、更新检查
- **CodeReviewService**: 代码质量分析、安全扫描

## 服务功能

### API 管理

```typescript
const apiService = adapter.getApiManagementService();

// 获取所有端点
const endpoints = await apiService.getAllEndpoints();

// 生成文档
const doc = await apiService.generateDocumentation('markdown');

// 测试 API
const testResult = await apiService.testApi({
  method: 'GET',
  url: 'http://api.example.com/users',
  headers: { 'Authorization': 'Bearer token' },
});
```

### 插件开发

```typescript
const pluginService = adapter.getPluginDevelopmentService();

// 获取模板
const templates = await pluginService.getAllTemplates();

// 创建插件项目
const files = await pluginService.createPlugin(
  'typescript-basic-plugin',
  'My Plugin',
  { author: 'Your Name' }
);

// 生成 API 对接指南
const guide = await pluginService.generateApiGuide(
  'plugin-id',
  apiEndpoints
);
```

### SDK 管理

```typescript
const sdkService = adapter.getSdkManagementService();

// 检查更新
const update = await sdkService.checkUpdates('javascript');

// 获取集成指南
const guide = await sdkService.generateIntegrationGuide(
  'javascript',
  'Node.js',
  'typescript'
);

// 获取版本历史
const versions = await sdkService.getVersionHistory('python');
```

### 代码审查

```typescript
const reviewService = adapter.getCodeReviewService();

// 审查代码
const result = await reviewService.reviewCode({
  code: 'function example() { ... }',
  language: 'javascript',
});

console.log('Score:', result.overallScore);
console.log('Issues:', result.issues);

// 扫描安全漏洞
const vulnerabilities = await reviewService.scanSecurityVulnerabilities(
  code,
  'typescript',
  'src/example.ts'
);
```

## 配置

### 默认配置

```typescript
{
  coreApiUrl: 'http://localhost:5000/api',
  wsEndpoint: 'ws://localhost:5000/ws',
  apiKey: undefined,

  services: {
    apiManagement: {
      enabled: true,
      autoDocument: true,
      testingEnabled: true,
    },
    pluginDevelopment: {
      enabled: true,
      templatesPath: './templates',
      autoGenerateDocs: true,
    },
    sdkManagement: {
      enabled: true,
      checkUpdatesInterval: 86400000,  // 24小时
      autoNotify: true,
    },
    codeReview: {
      enabled: true,
      strictMode: false,
    },
  },

  dialog: {
    maxHistoryLength: 100,
    timeout: 30000,
    enableStream: true,
  },

  developer: {
    preferredLanguage: 'typescript',
    codeStyle: 'eslint',
  },

  logging: {
    level: 'info',
    enableConsole: true,
  },
}
```

### 自定义配置

```typescript
const adapter = new XiaoyuanAdapter({
  apiKey: 'your-api-key',
  coreApiUrl: 'https://api.example.com/v1',
  wsEndpoint: 'wss://api.example.com/ws',

  services: {
    codeReview: {
      enabled: true,
      strictMode: true,
    },
  },

  logging: {
    level: 'debug',
  },
});
```

## 性能优化

1. **连接复用**: 保持长连接，避免频繁创建
2. **会话复用**: 复用会话对象，减少初始化开销
3. **消息批处理**: 批量处理相似请求
4. **缓存策略**: 缓存常用数据（如 API 端点列表）
5. **限流控制**: 实现请求限流，避免过载

---

## 安全最佳实践

1. **保护 API Key**: 使用环境变量，不要硬编码
2. **HTTPS/WSS**: 生产环境必须使用加密连接
3. **输入验证**: 验证所有输入数据
4. **错误信息**: 避免泄露敏感信息
5. **访问控制**: 实现适当的权限验证

## 故障排除

### 连接问题

```bash
# 检查服务是否运行
curl http://localhost:5000/api/xiaoyuan/health

# 检查 WebSocket 连接
wscat -c ws://localhost:5000/ws/xiaoyuan?token=your-token
```

### 常见错误

| 错误 | 原因 | 解决方案 |
|------|------|----------|
| `API key invalid` | API Key 无效 | 检查 API Key 是否正确 |
| `Connection failed` | 网络连接失败 | 检查网络和服务器状态 |
| `Service not enabled` | 服务未启用 | 在配置中启用对应服务 |
| `Session not found` | 会话不存在 | 创建新会话或检查会话 ID |
