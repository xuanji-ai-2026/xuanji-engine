## 📋 代码提交模板

### 提交信息格式

```bash
<type>(<scope>): <subject>
```

### 类型（type）

- `feat`: 新功能
- `fix`: 修复bug
- `docs`: 文档更新
- `style`: 代码格式（不影响功能）
- `refactor`: 重构
- `test`: 测试
- `chore`: 构建/工具链

### 范围（scope）

- `ziwei`: 紫微帝星（元灵层）
- `lucun`: 禄存星（调度层）
- `jumen`: 巨门星（记忆层）
- `tanlang`: 贪狼星（交互层）
- `lianzhen`: 廉贞星（人格层）
- `wuqu`: 武曲星（技能层）
- `pojun`: 破军星（执行层）
- `zuofu`: 左辅星（底座层）
- `youbi`: 右弼星（安全层）
- `fubi`: 辅弼星辰（扩展层）

### 主题（subject）

简洁描述，不超过50字符

### 示例

```bash
# 新功能
git commit -m "feat(ziwei): 完成意图理解模块"

# 修复
git commit -m "fix(lucun): 修复任务调度bug"

# 文档
git commit -m "docs: 更新API文档"

# 测试
git commit -m "test(jumen): 完成记忆层单元测试"
```
