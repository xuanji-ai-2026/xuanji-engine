## 一、模块定位与核心能力

### 1.1 模块定位

右弼星是玄玑AI数字员工引擎的安全防护核心，负责：
- **法律防火墙**: 5大类法律红线检测（人身安全、法律行为、信息安全、权利保护、执行禁区）
- **道德保护**: 4大类道德红线柔性防护（语言暴力、情感伤害、价值观冲突、隐私泄露）
- **权限控制**: RBAC/ABAC/ABX三引擎协同，精细化权限管理
- **IntentGuard意图对齐**: 计划门+工具门+意图漂移检测，降低误杀率
- **SafeMind具身安全**: 任务理解安全、多模态输入安全、物理操作安全
- **AI安全扫描**: CodeBERT静态分析、OWASP动态测试、插件自动化审计
- **区块链存证**: Hyperledger Fabric智能合约、不可篡改审计日志、司法级证据链
- **合规体系**: 等保三级22个控制点、GDPR六大原则、DPIA评估工具
- **应急响应**: 8大类应急预案、自动化响应、人在回路审批
